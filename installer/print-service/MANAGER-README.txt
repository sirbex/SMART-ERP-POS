SMART Print Service
===================

Installed for silent kitchen / bar / receipt printing with SMART ERP.

You do not need Node.js, PowerShell, or a terminal.

After install:
  1. Printer Setup Wizard opens (pick printers + test print).
  2. Open SMART ERP → Restaurant → Printers
  3. Confirm Printer Service is Online.

Start Menu: SMART-ERP-POS → SMART Print Service
Wizard:     SMART-ERP-POS → Printer Setup Wizard

Support: ask your SMART ERP administrator.
